# LumaCore Documentation

Welcome to the LumaCore documentation. This guide will help you understand, deploy, and develop with LumaCore - a **cross-platform .NET infrastructure** for self-hosting and orchestrating AI personas.

**LumaCore runs natively on Windows, Linux, and macOS** - with or without Docker.

## 📖 Documentation Philosophy

LumaCore documentation follows these principles:

### Clear and Complete
Every document provides enough context to understand the topic without jumping between files. We prefer being thorough over being minimal.

### Code-First
All examples and explanations are based on actual code from the repository. Nothing is invented or hypothetical unless explicitly marked as "Planned".

### Progressive Disclosure
Start with high-level concepts, then drill down into details. Each section builds on previous knowledge.

### Practical Examples
Every feature includes real-world examples with actual requests, responses, and configuration.
